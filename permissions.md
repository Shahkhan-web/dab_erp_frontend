# Purchases Module Permissions

Use these permission **keys** and **names** when adding permissions for the Purchases module.  
Format: `key` → **Permission Name**

---

## Module Access

| Key | Permission Name |
|-----|-----------------|
| `can_view_purchases` | View Purchases Module |
| `can_view_purchases_dashboard` | View Purchases Dashboard |

---

## Purchase Requests

| Key | Permission Name |
|-----|-----------------|
| `can_view_purchase_requests` | View Purchase Requests |
| `can_add_purchase_request` | Add Purchase Request |
| `can_edit_purchase_request` | Edit Purchase Request |
| `can_delete_purchase_request` | Delete Purchase Request |
| `can_view_purchase_request_detail` | View Purchase Request Detail |
| `can_approve_purchase_request` | Approve Purchase Request |
| `can_reject_purchase_request` | Reject Purchase Request |
| `can_cancel_purchase_request` | Cancel Purchase Request |
